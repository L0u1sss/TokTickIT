## Problem

Lab 4 requires a consistent Zen Green interface with reliable keyboard operation, responsive layouts and safe recovery across role dashboards, Actions Taken and earlier workflows. Query/hash context selected the wrong Staff screen or lost active navigation, long names pushed My Tickets controls outside the viewport, and blur validation could move Create Action before a pointer click finished. Communication validation and denied access also needed clearer feedback, while pending recovery/removal controls needed protection.

## Changes

- Resolve Staff/Admin screens and active navigation from the pathname while preserving query/hash context; make the Staff/Admin skip link explicitly focus main content.
- Wrap shell navigation, identity, dashboard headings and My Tickets headings; allow dashboard count grids to shrink and separate count labels/values. Remove page clipping that concealed overflow, and wrap long table text/filenames.
- Defer Action blur validation when focus moves to Submit so one pointer click validates the entire draft and focuses the first invalid field.
- Give Public Comment/Internal Note fields required/invalid/help semantics, first-invalid-field focus and shared Zen Green styling. Keep drafts after recoverable failure; hide prior entries and posting controls after 401/403/404; reject malformed successful responses safely.
- Lock repeated resolution indications and attachment removal; retain the modal/reason while removal is pending and allow Escape after recovery. Handle failed workflow reloads without unhandled rejection and disable recovery controls while pending.
- Add a deterministic UI audit for all three roles at desktop/tablet/mobile/reflow sizes: complete axe checks, actual control bounds, clipping/overlap, 44px mobile targets, keyboard drill-down/skip links, Action validation/Escape, modal trapping/focus return and safe draft recovery. Keep fixture screenshots/JSON separate from real API/database evidence.
- Extend component regression, CI, README and the verification runner. `--issue=60` stores fresh logs/source provenance separately from historical Issue #59 results. Update the completed visual/accessibility checklist and AI-use record.
